∑ Formula Reference

All vector calculus formulas used in VectorNav — with explanations

📚 This reference covers all mathematical formulas implemented in VectorNav. Each formula is applied to real GPS data — no random values.
Position Vector
r(t) = x(t)î + y(t)ĵ + z(t)k̂
What does this mean?
The position vector r(t) describes the location of a GPS receiver in 3D space at time t. x, y, z are ECEF (Earth-Centred Earth-Fixed) coordinates in metres derived from latitude, longitude, and altitude using the WGS-84 ellipsoid model.
Distance (Euclidean 3D)
d = √((x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²)
What does this mean?
The straight-line distance between two GPS positions in 3D ECEF space. For surface navigation, the Haversine formula is also used to compute the great-circle distance along the Earth's surface, accounting for Earth's curvature.
Velocity
v = dr/dt ≈ Δr / Δt
What does this mean?
Velocity is the rate of change of position with respect to time. For discrete GPS readings, this is approximated as the displacement vector Δr = r₂ − r₁ divided by the time difference Δt = t₂ − t₁. The result has components vx, vy, vz in m/s.
Speed (magnitude)
|v| = √(vx² + vy² + vz²)
What does this mean?
Speed is the scalar magnitude of the velocity vector — it tells us how fast the receiver is moving, without direction information. Expressed in m/s (convert × 3.6 for km/h).
Acceleration
a = dv/dt = d²r/dt² ≈ Δv/Δt
What does this mean?
Acceleration is the rate of change of velocity. For discrete GPS data, it is approximated as Δv/Δt between consecutive velocity estimates. A positive value means speeding up; negative means braking. Magnitude = √(ax²+ay²+az²) in m/s².
Direction (Unit Vector)
û = v / |v|
What does this mean?
The direction of motion is obtained by normalising the velocity vector to a unit vector. The heading (compass bearing) is computed using atan2(sin(Δλ)·cos(φ₂), cos(φ₁)·sin(φ₂)−sin(φ₁)·cos(φ₂)·cos(Δλ)) and mapped to N/NE/E/SE/S/SW/W/NW directions.
Gradient
∇f = (∂f/∂x)î + (∂f/∂y)ĵ
What does this mean?
The gradient of a scalar field f points in the direction of steepest increase. In GPS navigation context, f could represent elevation, signal strength, or traffic density. Moving against the gradient minimises resistance and aids route planning on varied terrain.
Divergence
∇ · F = ∂Fx/∂x + ∂Fy/∂y
What does this mean?
Divergence measures the net outward flow from a point in a vector field. In a traffic flow model, positive divergence indicates vehicles spreading out (highway merging); negative divergence indicates vehicles converging (bottleneck). It helps identify congestion points.
Curl
(∇ × F)_z = ∂Fy/∂x − ∂Fx/∂y
What does this mean?
Curl measures local rotational behaviour of a vector field. In 2D navigation, the z-component of curl indicates whether traffic is rotating (e.g., roundabouts) or flowing straight. An irrotational field (∇×F = 0) implies no circular patterns.
Line Integral
∫C F · dr = Σ Fᵢ · Δrᵢ
What does this mean?
A line integral accumulates the dot product of a vector field F with the displacement dr along a path C. In navigation, this can represent the total work done against wind or terrain resistance. A route with a smaller line integral is energetically more efficient.
GPS Error
Error = √((Δx)² + (Δy)² + (Δz)²)
What does this mean?
GPS error is the Euclidean distance between the true reference position and the measured GPS position in ECEF space. Sources include ionospheric delay, multipath, satellite geometry (DOP), and receiver noise. Error correction reduces this distance by applying a weighted correction factor to move the measured position towards the reference.
Route Cost Function
Cost = w₁·dist_norm + w₂·time_norm + w₃·error_norm
What does this mean?
A weighted sum of normalised route attributes (distance, time, GPS error) quantifies the overall cost of each route. Adjusting weights w₁, w₂, w₃ (which must sum to 1) shifts priority. The route with the lowest total cost is selected as optimal — a practical application of optimisation theory.
📐 WGS-84 ECEF Conversion Formulas
Converting Latitude (φ), Longitude (λ), Altitude (h) → ECEF (x, y, z)
a = 6,378,137.0 m   (WGS-84 semi-major axis)
f = 1 / 298.257223563   (flattening)
e² = 2f − f²   (eccentricity squared)
N(φ) = a / √(1 − e²·sin²(φ))   (prime vertical radius)

x = (N + h)·cos(φ)·cos(λ)
y = (N + h)·cos(φ)·sin(λ)
z = (N·(1 − e²) + h)·sin(φ)
