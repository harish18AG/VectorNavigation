ℹ About Project

Applied Mathematics + Computer Science

Capstone Project

Application of Vector Calculus in
Real-Time GPS Navigation Systems

A complete scientific application demonstrating how Position Vectors, Velocity, Acceleration, Gradient, Divergence, Curl, and Line Integrals underpin modern GPS navigation systems.
Applied Mathematics | Computer Science | GPS Systems Engineering
🎯 Project Goal

To develop a fully functional GPS navigation application that demonstrates the practical application of vector calculus concepts — including position vectors, velocity, acceleration, gradient, divergence, curl, and line integrals — through interactive real-time computation and visualization.

All mathematical values displayed are computed from actual GPS or Demo Mode data. No random values are used.

🚀 Quick Start Guide
1
Start the backend: Open terminal in vectornav/backend/ and run pip install -r requirements.txt then python app.py
2
Open the app: Navigate to http://localhost:5000 in your browser
3
Start Demo Mode: Click "▶ Start Demo" on the Dashboard to begin simulated GPS navigation with full math display
4
Explore modules: Visit Module 1, 2, 3 to see detailed step-by-step calculations, charts, and visualizations
